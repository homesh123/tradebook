# EdgeTrace – Trading Journal

A trading journal that finds the mistakes and behaviour patterns costing you money – and tells you how to fix them.

- **Use it**: https://homesh123.github.io/tradebook/, then press `?` for the in-app guide.
- **Docs**: [docs/DOCUMENTATION.md](../docs/DOCUMENTATION.md)
- **Source**: this folder – `npm install && npm start`; `npm run deploy` publishes the build to the repo root.
